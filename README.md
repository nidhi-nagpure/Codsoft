# CODSOFT Data Science Internship

## About

This repository contains the projects completed as part of the CODSOFT Data Science Internship.

## Projects

### 1. Iris Flower Classification

**Objective:** Classify Iris flowers into Setosa, Versicolor, and Virginica species based on flower measurements.

**Algorithm Used:** Decision Tree Classifier

**Tools & Libraries:**

* Python
* Google Colab
* Pandas
* Scikit-Learn

---

### 2. Titanic Survival Prediction

**Objective:** Predict whether a passenger survived the Titanic disaster using passenger information.

**Algorithm Used:** Random Forest Classifier

**Features Used:**

* Passenger Class
* Gender
* Age
* Fare

**Tools & Libraries:**

* Python
* Pandas
* NumPy
* Scikit-Learn

---

### 3. Sales Prediction Using Python

**Objective:** Predict product sales based on advertising expenditure.

**Algorithm Used:** Linear Regression

**Features Used:**

* TV Advertising
* Radio Advertising
* Newspaper Advertising

**Tools & Libraries:**

* Python
* Pandas
* Scikit-Learn

---
